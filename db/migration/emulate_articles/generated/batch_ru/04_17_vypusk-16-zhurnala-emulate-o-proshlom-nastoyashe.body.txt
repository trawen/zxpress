ПРОШЛЫЕ ВЫПУСКИ

Все прошлые номера можно взять на Frazzle
Project BBS, FTP NVG UNIT (каталог:
pub/sinclair/snaps/discmag/emulate) или FTP
DEMON (каталог:
pub/emulators/spectrum/magazines/emulate).
Кратко о содержании последних четырёх
номеров:

==========================================

ВЫПУСК 1 — сентябрь 1995
A-Z игр Spectrum, часть 1; история Spectrum,
часть 1; полный гид по Dizzy; Rebelstar
Review Guide; огромный список Multiface POKE,
приключения и игровые чарты.

SNAPSHOT PACK: Pyjamarama, 16/48 No.20,
JSW Editor, Jet Set Willy 3, Chaos Editor,
War In Middle Earth, Twice Shy, набор GIF и
две утилиты — SPCONV и POKE-IT.

==========================================

ВЫПУСК 2 — октябрь 1995
A-Z игр Spectrum, часть 2; история Spectrum,
часть 2; гид взломщика к Doomdark's Revenge;
советы по Pyjamarama, Bards Tale и Retarded
Creatures and Caverns; обзор Spectrum
database; полный гид по чартам Spectrum и
Desert Island Disks.

SNAPSHOT PACK: Everyones a Wally, 16/48 No.3,
The Bards Tale, Rock Star Ate My Hamster,
Loads of Midnight, Retarded Creatures and
Caverns, Spectrum Test Program, POKE
Database, плюс две ЭКСКЛЮЗИВНЫЕ игры — Join
the Jet Set и предрелиз Street Hawk.

==========================================

ВЫПУСК 3 — ноябрь/декабрь 1995
A-Z игр Spectrum, часть 3; история Spectrum,
часть 3; полный гид по Magic Knight; база
книг Spectrum, часть 1; решения для
Everyones A Wally, Stormbringer, Finders
Keepers и Spellbound.

SNAPSHOT PACK: Demon From The Darkside, Crazy
Caverns, Deathstalker, Herberts Dummy Run и
бонусная головоломка, Robocop (128k), 16/48
No.24, Graham Gooch's Cricket, Technician Ted
2 - Costa Capers, Jet Set Willy Editor II,
плюс ЭКСКЛЮЗИВ — Jet Set Willy - The
continuing adventures.

==========================================

SPECIAL 1 — зима 1995
Первый спецвыпуск Emulate — огромный A-Z с
подсказками, советами, pokes и решениями
для сотен игр. Сборник из Your Sinclair —
дополнение «Smash Tips»; теперь в ASCII и
HTML!!

==========================================
